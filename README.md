# Flappy Bird (Pygame)

A classic 2D Flappy Bird clone built using Python and Pygame. Navigate the bird through moving obstacle pipes, keep track of your score, and try to beat your personal high score!

## Features

- **Smooth Gameplay Loop:** Runs at 60 FPS with physics gravity and jumping mechanics.
- **Dynamic Obstacle Generation:** Spawns random pipe gaps every 1.5 seconds.
- **Score Tracker:** Visual score display that changes dynamically during gameplay and game-over states.
- **PyInstaller Compatibility:** Implements `resource_path` logic to allow effortless bundling into executable `.exe` files.

## Requirements
- **Python 3.x**
- **pygame library**
- **flappybird.png**
- **flappybirdbg.png**
- **flappybirdicon.ico**
- **toppipe.png**
- **bottompipe.png**
